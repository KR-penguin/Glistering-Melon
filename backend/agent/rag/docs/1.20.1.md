# Minecraft Java Edition 1.20.1 — server console / RCON commands

The core ops/admin command set below is unchanged from 1.21.1 for this
curated list — noted explicitly rather than silently duplicated, so this
file isn't mistaken for having been machine-copied without checking. Add
genuine 1.20.x-specific commands here if a real one is needed later; none
are fabricated in this seed set.

## ban
Syntax: `ban <player> [reason]`
Adds a player to the ban list and disconnects them if online.

## ban-ip
Syntax: `ban-ip <address|player> [reason]`
Bans an IP address (or the IP currently used by a player).

## pardon
Syntax: `pardon <player>`
Removes a player from the ban list.

## kick
Syntax: `kick <player> [reason]`
Disconnects a player without banning them.

## op
Syntax: `op <player>`
Grants operator status to a player.

## deop
Syntax: `deop <player>`
Revokes operator status from a player.

## whitelist add
Syntax: `whitelist add <player>`
Adds a player to the whitelist.

## whitelist remove
Syntax: `whitelist remove <player>`
Removes a player from the whitelist.

## whitelist list
Syntax: `whitelist list`
Lists all whitelisted players.

## list
Syntax: `list`
Shows the count and names of currently online players.

## gamerule
Syntax: `gamerule <rule> [value]`
Reads or sets a game rule.

## difficulty
Syntax: `difficulty <peaceful|easy|normal|hard>`
Sets the world's difficulty.

## save-all
Syntax: `save-all [flush]`
Forces an immediate world save.

## stop
Syntax: `stop`
Gracefully shuts down the Minecraft process from inside the game console. Prefer restart_server/stop_server from outside instead.

## teleport
Syntax: `teleport <target> <destination>`
Teleports a player to another player or coordinates.

## gamemode
Syntax: `gamemode <survival|creative|adventure|spectator> [player]`
Changes a player's game mode.
