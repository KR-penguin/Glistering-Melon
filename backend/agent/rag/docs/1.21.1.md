# Minecraft Java Edition 1.21.1 — server console / RCON commands

Curated ops reference for the commands this agent is actually expected to
run via RCON. Not exhaustive game-command coverage — just the admin set.

## ban
Syntax: `ban <player> [reason]`
Adds a player to the ban list and disconnects them if online. `reason` is optional free text shown to the player.

## ban-ip
Syntax: `ban-ip <address|player> [reason]`
Bans an IP address (or the IP currently used by a player) rather than just the account.

## pardon
Syntax: `pardon <player>`
Removes a player from the ban list.

## pardon-ip
Syntax: `pardon-ip <address>`
Removes an IP address from the ban list.

## kick
Syntax: `kick <player> [reason]`
Disconnects a player without banning them; they can rejoin immediately.

## op
Syntax: `op <player>`
Grants operator (admin) status to a player.

## deop
Syntax: `deop <player>`
Revokes operator status from a player.

## whitelist add
Syntax: `whitelist add <player>`
Adds a player to the whitelist. Requires the player to have joined before or a valid known username.

## whitelist remove
Syntax: `whitelist remove <player>`
Removes a player from the whitelist.

## whitelist list
Syntax: `whitelist list`
Lists all whitelisted players.

## whitelist on
Syntax: `whitelist on`
Enables whitelist enforcement.

## whitelist off
Syntax: `whitelist off`
Disables whitelist enforcement (anyone can join).

## whitelist reload
Syntax: `whitelist reload`
Reloads the whitelist from disk (use after editing whitelist.json directly).

## list
Syntax: `list`
Shows the count and names of currently online players.

## say
Syntax: `say <message>`
Broadcasts a message to all players in chat, prefixed as a server message.

## tell
Syntax: `tell <player> <message>`
Sends a private message to one player. `msg` and `w` are aliases.

## gamerule
Syntax: `gamerule <rule> [value]`
Reads or sets a game rule, e.g. `gamerule keepInventory true`, `gamerule doDaylightCycle false`.

## difficulty
Syntax: `difficulty <peaceful|easy|normal|hard>`
Sets the world's difficulty.

## time set
Syntax: `time set <day|noon|night|midnight|<ticks>>`
Sets the in-game time.

## weather
Syntax: `weather <clear|rain|thunder> [duration]`
Sets the current weather.

## save-all
Syntax: `save-all [flush]`
Forces an immediate world save. `flush` waits for the write to complete before returning.

## save-off / save-on
Syntax: `save-off` / `save-on`
Disables/re-enables automatic world autosaving (used around manual backup snapshots).

## stop
Syntax: `stop`
Gracefully shuts down the Minecraft *process* from inside the game console. Prefer the agent's restart_server/stop_server tools instead when acting from outside — they work even if this command would hang.

## teleport
Syntax: `teleport <target> <destination>`
Teleports a player to another player or coordinates. `tp` is an alias.

## gamemode
Syntax: `gamemode <survival|creative|adventure|spectator> [player]`
Changes a player's game mode.

## give
Syntax: `give <player> <item> [count]`
Gives an item to a player.

## effect give
Syntax: `effect give <player> <effect> [seconds] [amplifier]`
Applies a status effect to a player.

## kill
Syntax: `kill <target>`
Kills the specified entity/player instantly.

## setworldspawn
Syntax: `setworldspawn [x y z]`
Sets the world spawn point to the given coordinates, or the command's current position if omitted.
